# Shopify WhatsApp CRM - Setup & Deployment Guide

Welcome to the Shopify WhatsApp CRM Plugin! This guide will walk you through setting up the application locally, running it, uploading it to the Shopify Partner Dashboard, and installing it on a store.

## 1. Local Setup Instructions

Before running the app, you need to configure your local environment and database.

### Prerequisites
- Node.js (v18 or higher)
- A MySQL Database (Local or Cloud like PlanetScale / AWS RDS)
- A Shopify Partner Account

### Step 1: Configure Environment Variables
Create a file named `.env` in the root of the project directory (`shopify-whatsapp-crm`) and add your database credentials:

```env
# Your MySQL Database URL
DATABASE_URL="mysql://username:password@localhost:3306/shopify_crm"
```

### Step 2: Install Dependencies
Open your terminal in the project directory and run:
```bash
npm install
```

### Step 3: Setup the Database
Push the Prisma schema to your MySQL database to create the required tables:
```bash
npm run prisma db push
```

## 2. Running the Application Locally

Once the setup is complete, you can start the development server.

### Step 1: Start the Dev Server
Run the following command in your terminal:
```bash
npm run dev
```

### Step 2: Authenticate with Shopify
The CLI will prompt you to log in to your Shopify Partner account. Press any key to open the browser and authorize the CLI.

### Step 3: Select an App and Store
The CLI will ask if you want to create a new app or connect to an existing one. 
- Choose **Create it as a new app**.
- Name it **WhatsApp CRM**.
- Select a **Development Store** to preview your work.

The CLI will automatically set up a secure Cloudflare tunnel and provide you with a URL to view your app inside the Shopify Admin.

## 3. Plugin Upload Process (Deploying)

When you are ready to upload the plugin to Shopify's servers for production use, follow these steps:

### Step 1: Build the Application
Compile the Remix application for production:
```bash
npm run build
```

### Step 2: Deploy to Hosting
You cannot host a Shopify app directly on Shopify. You must host this Node.js app on a provider like Vercel, Heroku, Railway, or AWS.
1. Connect your GitHub repository to your hosting provider.
2. Add your `DATABASE_URL`, `SHOPIFY_API_KEY`, and `SHOPIFY_API_SECRET` to the environment variables on your hosting provider.
3. Deploy the application. You will receive a production URL (e.g., `https://my-whatsapp-crm.herokuapp.com`).

### Step 3: Update Shopify App Settings
1. Go to your [Shopify Partner Dashboard](https://partners.shopify.com).
2. Click on **Apps** and select your app.
3. Go to **Configuration**.
4. Update the **App URL** to your new production hosting URL.
5. Update the **Allowed redirection URL(s)** to `https://your-production-url.com/auth/callback` and `https://your-production-url.com/auth/shopify/callback`.

## 4. Plugin Install Process

To install your newly deployed or local app on a merchant's store:

### Option A: Install via the Partner Dashboard (For Testing)
1. In your Shopify Partner Dashboard, navigate to your App.
2. Click on **Test your app**.
3. Select a Development Store from the dropdown.
4. Click **Install app**. You will be redirected to the store's admin panel to approve the required permissions.

### Option B: Install via Installation Link (For Merchants)
If your app is custom or not listed on the App Store, you can generate an installation link:
1. Construct a URL like this:
   `https://[shop-name].myshopify.com/admin/oauth/install?client_id=[your_shopify_api_key]`
2. Send this link to the merchant.
3. When they click it, they will be prompted to log into their store and approve the installation of your WhatsApp CRM.
